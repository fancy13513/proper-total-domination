# 环面网格上的适当全支配集

本项目给出一个存在性分类和一个精确的极小化结果。图上的每个顶点可以标记或留白。每个顶点至少要有一个被标记的邻居，相邻顶点的标记邻居数还必须不同。环面网格的上下、左右边界分别首尾相连。

## 结论

1. 对边长均为奇数且均不小于 5 的环面棋盘，恰有 **5 × 5** 无解。结合 Osborn 与 Zhang 已证明的边界情形，就得到两个圈的所有笛卡尔积的存在性分类。
2. 对 **5 × n**，若 n ≥ 12，最少标记数恰为 **5⌈n/2⌉**。例如 5 × 101 最少用 255 枚；取到下界的含义既包括存在这个大小的摆法，也包括所有更小摆法都不可行。短边为 5 的最优密度随 n 趋于无穷收敛到 1/2。
3. 对一般奇数边长，邻居计数还给出一个无需计算机的通用下界，见中文证明。

| n | 3 | 4 | 5 | 6 | 7 | 8 | 9 | 10 | 11 |
|---|---:|---:|---:|---:|---:|---:|---:|---:|---:|
| 5 × n 所需的最少标记数 | 无解 | 12 | 无解 | 15 | 20 | 21 | 26 | 25 | 31 |

## 本地复现

在仓库根目录运行。主验证需要 Python 3.8 或更高版本（标准库），以及 PATH 中可用的 GNU g++ 或 clang++（C++17）。可在 Windows 上使用 MinGW-w64 或 WSL。完整验证在临时目录编译两个小程序并与已记录的整数结果比较。

```sh
python reproduce.py
```

最后一行应为 `PASS`。仅检查八张种子和 5 × 5 的逐行枚举，无需 C++ 编译器，可执行 `python verification/verify.py`。如已安装 NumPy，使用 `python reproduce.py --cross-check` 再运行元组编码的独立验证；该验证按旋转对称性精简起点，但保留全部标号终点。

| 程序或数据 | 作用 |
|---|---|
| `verification/verify.py` | 八张 0–1 种子，验证 20 张局部展开棋盘，逐行排除 5 × 5 |
| `verification/exhaustive_5x5.cpp` | 直接枚举所有 33,554,432 张有标号的 5 × 5 棋盘 |
| `verification/width_five.cpp` | 构建转移图并核对全部 18,576,100 对起点、终点的递推恒等式 |
| `verification/recheck.py` | 独立构图验正例，用目标列计费、反向建边，核对最优值与周期 |
| `verification/search_seeds.py` | 可选。产生用于发现种子的 SMT-LIB 约束，验证上述结论无需安装 Z3 |
| `results/` | 编译计算与两个 Python 校验程序的输出，含 n = 3 至 50 的所有最优值 |

要重新搜索一张双向可扩展的 9 × 9 种子，可以执行下列命令。不同 Z3 版本可给出不同的合法摆法。

```sh
python verification/search_seeds.py 9 9 --axes RC > seed.smt2
z3 seed.smt2
```

在标准 TeX Live 环境中，进入 `paper/` 连续执行两次 `pdflatex manuscript.tex` 可生成含内部交叉引用的排版稿。
